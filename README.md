## 电波女仆 / 遥控女仆 / 心有灵犀

本模组以勤劳跟踪狂为前置，使女仆成为可操控实体，玩家可以通过手办绑定女仆，并无视距离随时进入电波指挥模式，协助女仆行动。

在该模式下，玩家可共享女仆视角，操作女仆移动，远程切换任务，随时开关女仆GUI。

通过本模组，女仆不再一直是可可爱爱、没有脑袋的样子，必要的时候可以由玩家手把手协助以达到1+1>2的效果。

### 如何开始

在开启电波指挥之前，首先需要制作女仆的专属手办：

- 制作文文的相机，拍下女仆的照片。
- 副手持女仆照片，主手持雕刻刀，雕刻出1×1大小粘土雕像。
- 粘土雕像置于火焰上方，一段时间后烧制成手办。

主手持女仆手办，对着女仆潜行右键即可绑定唯一女仆实体，一个手办只能进行一次绑定。

该手办与女仆的绑定体现为三个地方：

- 手办使用者为女仆主人。
- 手办记录的UUID与女仆相符。
- 手办的模型与女仆相同。

当条件完全符合时，玩家手持手办即可高亮显示对应女仆。

### 电波指挥

主手持已绑定的女仆手办右键，即可进入女仆视角，并显示特殊HUD：

![img](https://resource-api.xyeidc.com/client/pics/151d5424)

屏幕中央是女仆的状态，如信号和能源，超出信号范围将无法操控，当前版本暂未将启用能源设定，后续如果启用，将以糖作为能源。

屏幕左下方是女仆的实体渲染，展示女仆当前状态，右下方则是女仆手持物品。

屏幕上方是主人的方向和距离，该图标位置会随时变化。

屏幕中间底部的文字是任务指示器，指示女仆当前分配的任务，使用鼠标滚轮可以快速切换任务。

屏幕左上角是与灵活按键提示适配的按键提示，推荐一并安装使用，详细功能如下：

- 默认按R退出电波指挥模式，如果此时女仆处于跟随模式，那么她将传送到主人身边。
- 默认按C开关操作输入，当开启操作输入时，玩家的前后左右和跳跃潜行操作输入将指挥女仆的行动，等同于是玩家在操作。关闭操作输入时，女仆将继续原本笨笨的AI活动。
- 默认按V切换视角模式，可切换自由、跟随、控制三种模式，跟随模式下等同于观察者模式观察实体，控制模式下玩家可以让女仆看向指定的方向。

屏幕正中央的玩家有很好看的框，女仆视线所指的实体会用金色线框高亮，玩家可以方便知道女仆在看什么。

除此之外，电波指挥还具有以下特性：

- 电波指挥无视距离，哪怕女仆在未加载的区块上，也能强制加载区块并与女仆建立电波联系，电波指挥下的女仆会像玩家一样不断加载并渲染周围区块。
- 电波指挥下，玩家打开物品栏的热键E会打开女仆的GUI，但其中并不会显示玩家物品栏，除此之外与通常使用时无异，可以便捷地进行调整女仆物品栏等操作。
- 电波指挥无法跨区块使用。

### 注意事项

- 跟随模式下，如果女仆处于电波指挥之下，她将不会自动传送到主人身边。
- 如果希望女仆始终呆在一个很远的地方，请在退出电波指挥前将其设置为HOME模式。
- 如果在电波指挥模式下出现视角无法移动，区块无法加载等情况，请反馈至勤劳跟踪狂。
- 配合很重要，以枪械任务模式为例，玩家可以代替女仆走位和选择瞄准对象，而女仆会自动开火和压枪。
